# Generated Petalbound asset drafts

These original AI-generated sheets are kept separate from shipped game art while they are being reviewed. All PNGs are 1920×1920 with transparent backgrounds.

- `items_sheet.png` — 4×4 grid: 16 item/resource icons, ordered left-to-right then top-to-bottom.
- `weapons_sheet.png` — 3×3 grid: 9 weapon concepts, ordered left-to-right then top-to-bottom.
- `gear_sheet.png` — 3×3 grid: 9 equipment/relic concepts, ordered left-to-right then top-to-bottom.
- `mallow_walk_sheet.png` — 4×4 animation concept: four-frame rows facing down, left, right, then away/back.

These are **draft atlases**, not yet sliced into production-sized sprites or connected to the item database/animation player. Review and crop individual cells before replacing any live game assets; generated sprite spacing and animation timing should be checked in-game first.
